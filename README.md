# 🏥 MediCore Infrastructure & Security Deployment

Welcome to the repository for the MediCore clinical infrastructure project. This repository contains the Infrastructure as Code (IaC), containerisation configurations, Kubernetes security manifests, and Python data analysis scripts developed to secure and deploy the MediCore clinical application.

Given the sensitive nature of healthcare data, this deployment was engineered with a strict defence-in-depth approach, focusing on host OS hardening, container isolation, and automated high availability.

### 📄 Final Assignment Documentation
⚠️ **Please refer to the `Written Report (Deliverable B).pdf` located in the root of this repository.** 

The report contains the comprehensive technical breakdown, architectural diagrams, visual terminal evidence, and security justifications for all configurations found in this repository.

---

## 📂 Repository Structure

The technical evidence for this assignment is organized into the following directories:

* **`/infrastructure`**
  Contains the shell scripts and documentation used to harden the foundational Ubuntu host Virtual Machine (enforcing the Principle of Least Privilege, `auditd` logging, and UFW default-deny network rules).
* **`/docker`**
  Contains the highly optimized, multi-stage `Dockerfile` enforcing non-root execution, alongside the CI/CD vulnerability scanning reports generated by Trivy and Grype.
* **`/kubernetes`**
  Contains the YAML deployment and service manifests used to orchestrate the application. These manifests enforce High Availability (HA), self-healing, resource limits, and strict Pod Security Contexts.
* **`/analysis`**
  Contains the Python data analysis script (`analyse.py`), the `pandas` requirements, and the clinical infrastructure monitoring dataset used for Deliverable A6.
* **`/screenshots`**
  The visual evidence vault containing all terminal outputs referenced as Figures within the final written report.
